## Задание 2

Принято явное допущение: «2 любых корма» означает **не менее двух единиц подходящего корма суммарно за 1–15 августа включительно**, в одном или разных заказах. Один SKU в количестве 2 подходит.

Отбор: категория «Продукция для животных», название начинается с «Корм » либо «Паштет ». Лакомства и остальные товары категории не включаются. SKU `3107` («Корм Kitekat для кошек, с кроликом в соусе, 85 г») исключён из суммирования. Его дополнительная покупка не исключает пользователя. После исключения в справочнике 66 подходящих SKU.

Результат — **4 169 пользователей**. При трактовке «ровно две единицы» получилось бы 2 316, при «не менее двух разных SKU» — 2 996. В сдаваемом XLS используется основной вариант. Прежняя логика всей категории давала 5 228 пользователей, включая покупки товаров, не относящихся к корму.

## Задание 3

SQL рассчитан на PostgreSQL и использует те же четыре бизнес-таблицы: `orders`, `order_lines`, `products`, `warehouses`. Первый заказ определяется до фильтра периода и города, по всей доступной истории пользователя. При одинаковой дате выбирается меньший числовой `order_id`, поскольку времени заказа нет.

После ранжирования отбираются первые заказы в Санкт-Петербурге за **15–30 августа включительно**. Частота товара — число различных первых заказов с ним; `quantity` и дубли строк не увеличивают частоту одного заказа. Неизвестные SKU сохраняются через `LEFT JOIN`. При равной частоте сортировка по текстовому `product_id` фиксирует результат.

| product_id | Товар | Первых заказов |
|---|---|---:|
| 3107 | Корм Kitekat с кроликом в соусе, 85 г | 590 |
| 9736 | Свекла вареная очищенная, 500 г | 399 |
| 1687 | Крабовые палочки Бухта Изобилия, 200 г | 394 |
| 2870 | Йогурт Чудо питьевой, вишня и черешня, 270 г | 394 |
| 3950 | Икра трески Санта Бремор Pate, 90 г | 353 |

Всего отобрано 13 329 первых наблюдаемых заказов. История начинается 1 августа: это не гарантированно первые покупки клиента за всё время. Исключение Kitekat действует только в задании 2.

## Подготовка модели

Предоставленный `Самокат_2.pbix` использован как основа. Исправлены источники, локаль цены, подсчёт неизвестных складов, отбор кормов и обработка строк без заголовка. Страницы отчёта переоформлены, добавлен параметр `SourceFolder`. Исходные выгрузки и исходный PBIX не изменены.

Все преобразования модели выполняются **в Power Query внутри Power BI**. `products` читается в Mac Cyrillic 10007, остальные выгрузки — UTF-8. `order_lines` использует табуляцию. ID остаются текстом. Одна цена `16,5` нормализуется в поле `price`; дополнительная точность других цен сохраняется. Из `orders` и `products` удалены только точные дубли (65 и 15 соответственно). 65 повторяющихся товарных строк сохранены: без `line_id` нельзя доказать, что они технические.

Связи односторонние: `warehouses (1) → orders (*) → order_lines (*)`, `products (1) → order_lines (*)`, `Calendar (1) → orders (*)`. Служебные `Calendar`, `DAX` и `orders (2)` не меняют набор четырёх бизнес-таблиц SQL. Полные M-запросы и DAX доступны в `powerbi/`; `model.bim` и `Samokat.Report/` содержат читаемые определения модели и страниц для проверки и контроля версий.

## Воспроизведение

Для просмотра откройте `Samokat_complete.pbix` в Power BI Desktop. Импортированные данные уже сохранены. Для обновления откройте **Преобразование данных → Управление параметрами**, задайте `SourceFolder` — папку с четырьмя оригинальными выгрузками — и выполните обновление. Имена исходных файлов сохранены в запросах.

Независимая проверка по оригиналам:

```powershell
python -m pip install -r requirements.txt
python src/analyze.py --source "C:\папка\с\исходными\выгрузками"
python -m unittest discover -s tests -v
```

Скрипт не изменяет источники и не подменяет Power Query. Он сохраняет контрольные таблицы в `output`, проверяет уникальность ключей и сопоставляет результаты SQL с pandas. Для повторного формирования Excel требуется экспорт списка из Power BI в Excel 97–2003; исходный XLS уже включён в результат.

## Проверки и ограничения

- Модель полностью обновлена из оригинальных файлов; KPI и 4 169 пользователей проверены запросом DAX в работающем Power BI и независимым расчётом.
- SQL обоих заданий выполнен в SQLite; для кириллического `LOWER` зарегистрирована Unicode-функция Python. Результаты совпали с pandas. PostgreSQL-сервер и производительность запроса не проверялись.
- Граничные тесты проверяют даты 1/15/16/30/31 августа, суммирование между заказами, исключённый SKU, выбор первого заказа до города и периода, ничьи по дате, повторные строки и неизвестный товар.
- XLS открыт в Microsoft Excel: формат 56 (Excel 97–2003), 4 170 строк с заголовком, один столбец, без формул; все ID совпали с контрольным CSV.
- Исходные выгрузки не приложены отдельными файлами согласно условию задания. PBIX содержит импортированную модель; SHA-256 оригиналов записаны в `summary.json`.
- Два нестандартных `user_id` сохранены и описаны в конспекте. 72 804 — число значений идентификатора, а не подтверждённое число людей.

Полный исходный код, определения Power BI, контрольные CSV и скриншоты находятся в этом комплекте. Письмо HR не отправлялось.
